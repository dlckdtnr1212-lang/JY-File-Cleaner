## 1. 프로그램 개요

**JY File Cleaner v2.0 Beta**는 일반 Windows 사용자가 복잡한 설정 없이도 디스크 용량을 확보하고 지저분해진 파일들을 체계적으로 관리할 수 있도록 설계된 올인원 유틸리티입니다.

단순 임시 파일 삭제에 그치지 않고, 다운로드 폴더 자동 분류, 3단계 SHA-256 중복 파일 탐색, Pillow 지각 해시(dHash) 기반 유사 사진 비교, 대량 파일명 변경 및 이미지 포맷 일괄 변환, 백업 대조 기능을 최신 Fluent UI를 통해 직관적으로 제공합니다.

## 3. 안심 파일 관리 4대 원칙 (안전 최우선)

1. **영구 삭제 없는 Windows 휴지통 이동 (`IFileOperation`)**:
   어떤 파일도 확인 없이 영구 삭제되지 않으며, 모두 복원 가능한 Windows 휴지통으로 안전하게 이동됩니다.
2. **클라우드 동기화 경로 자동 보호**:
   OneDrive, Google Drive, Dropbox 등 동기화 폴더가 포함된 경우 자동으로 보호 경고를 적용합니다.
3. **중복 그룹 마지막 사본 강제 보존**:
   사용자가 실수로 중복 그룹의 모든 사본을 선택하더라도 프로그램이 자동으로 감지하여 삭제를 원천 차단합니다.
4. **다운로드 이동 이름 충돌 방지**:
   목적지 폴더에 동일한 이름의 파일이 이미 존재할 경우 자동으로 `(1)`, `(2)` 번호를 증분하여 덮어쓰기를 방지합니다.

## 4. 실행 및 다운로드 안내

### 독립 실행본 다운로드 (권장)
GitHub Releases에서 `JY_File_Cleaner_v2.0_Beta.zip`을 내려받아 압축 해제 후 `JY_File_Cleaner_v2.0_Beta.exe`를 더블클릭합니다.
- **기본 실행**: 최신 Fluent 8대 메뉴 WebView2 UI가 자동 실행됩니다.
- **레거시 실행**: `JY_File_Cleaner_v2.0_Beta.exe --classic` 입력 시 경량 Tkinter 화면으로 시작합니다.

### 🛡️ Windows Defender SmartScreen 알림 발생 시
Windows Defender SmartScreen의 "Windows의 PC 보호" 파란색 창이 표시되는 경우:
1. 창 왼쪽 상단의 **[추가 정보]**를 클릭합니다.
2. 우측 하단의 **[실행]** 버튼을 클릭하면 프로그램이 즉시 정상 실행됩니다.

### 🌐 Microsoft Edge WebView2 런타임 안내
- 최신 8개 메뉴 Fluent UI를 구동하기 위해 Microsoft Edge WebView2 Runtime이 필요합니다.
- Windows 11 및 최신 Windows 10에는 기본 탑재되어 있습니다.
- 미설치된 PC에서는 [마이크로소프트 공식 WebView2 설치 페이지](https://go.microsoft.com/fwlink/p/?LinkId=2124703)에서 Evergreen Bootstrapper를 무료 다운로드하여 설치하실 수 있습니다.
