# JY File Cleaner v2.0 Beta

**JYrun이 만든 무료 Windows 파일 관리 프로그램**입니다. Windows 10/11 64비트를 대상으로 하며, ZIP을 압축 해제해 실행합니다. Python 설치는 필요하지 않습니다.

## 무엇을 할 수 있나요?

| 메뉴 | 주요 기능 |
| --- | --- |
| 통합 대시보드 | 드라이브 상태와 최근 분석 결과 확인 |
| 디스크·파일 정리 | 정리 후보, 대용량 파일·폴더 TOP 20, 빈 폴더 및 0바이트 파일 탐색 |
| 다운로드 스마트 정리 | 파일 종류별 분류, 이동 계획 확인, 이름 충돌 방지 |
| 중복 파일 탐색 | SHA-256으로 내용이 같은 파일 검색, 남길 사본 확인 |
| 사진·동영상 관리 | 시각적으로 유사한 사진 탐색과 나란히 비교. 유사 동영상 탐색은 제공하지 않습니다. |
| 파일 편의 도구 | 파일명 일괄 변경, 이미지 변환, EXIF 정보 확인 |
| 백업·폴더 비교 | 폴더 또는 ZIP을 기준으로 다른 폴더와 일치·변경·누락·신규 항목 비교 |
| 설명서·정보 | 사용법과 보호 규칙, 버전 정보 확인 |

## 다운로드와 실행

1. [v2.0 Beta 배포 페이지](https://github.com/dlckdtnr1212-lang/JY-File-Cleaner/releases/tag/v2.0-beta)에서 `JY_File_Cleaner_v2.0_Beta.zip`을 받습니다.
2. ZIP을 **전체 압축 해제**합니다. ZIP 안의 EXE를 바로 실행하거나 EXE만 따로 복사하지 마세요.
3. 압축 해제한 폴더의 `JY_File_Cleaner_v2.0_Beta.exe`를 실행합니다. `_internal` 폴더와 배포 구성 파일은 함께 두세요.

## 파일을 정리하기 전에

- 검사 결과와 실제 이동 대상, 파일 경로를 먼저 확인하세요. 정리 시뮬레이션은 계획을 확인하는 단계입니다.
- OneDrive 동기화 파일과 시스템·프로그램 의존 파일에 보호 규칙이 적용됩니다. 버튼이 비활성화되면 보호 사유를 확인하세요.
- 중복 파일과 유사 사진에서는 보관할 원본을 최소 한 개 남기세요. 유사 사진의 점수는 시각적 유사도이며 파일 내용이 같다는 뜻은 아닙니다.
- 휴지통 이동 후 복원 가능 여부는 Windows 설정과 사용 환경에 따라 달라집니다. 중요한 파일은 별도로 백업하세요.

## 베타 검증 및 의견 보내기

Candidate 50은 **Windows 10 64비트**에서 압축 해제·EXE 실행, D드라이브 빈 폴더 탐색, 다운로드 정리 후 목록 갱신, 한글·쉼표가 포함된 파일의 위치 열기, 백업 비교 필터, OneDrive 보호 파일의 삭제 버튼 비활성화를 사용자가 직접 확인했습니다. Windows 11 실기 및 모든 PC 환경에서의 동작까지 확인한 것은 아닙니다.
