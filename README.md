# JY File Cleaner v2.0 Beta

**무료 Windows 통합 파일 분석·정리 도구 | 한국어 UI | Developed by JYrun**

JY File Cleaner는 중복 파일, 유사 사진, 디스크 용량, 다운로드 폴더 등을 한곳에서 분석하고 관리할 수 있도록 제작한 Windows용 무료 프로그램입니다. 복잡한 전문 용어보다 **무엇을 확인하고 어떻게 안전하게 정리할지** 알기 쉬운 화면과 설명을 지향합니다.

> **현재 상태:** v2.0 Beta. 실제 사용 환경에 따라 오류가 있을 수 있으므로 중요한 자료는 미리 백업하고, 검사 결과와 정리 대상을 확인해 주세요.

## 📥 공식 다운로드

## 🧰 주요 기능

| 메뉴 | 기능 |
| --- | --- |
| **대시보드** | 주요 드라이브와 파일 관리 현황 요약 |
| **디스크·파일 정리** | 정리 후보 분석, 보호·검토 구분, 대용량 파일 TOP 20, 폴더 용량 TOP 20, 빈 폴더 및 0바이트 파일 탐색 |

| **중복 파일 탐색** | 파일 내용 해시(SHA-256) 기반 완전 중복 검색, 원본 보존을 고려한 선택 정리 |
| **사진·동영상 관리** | 유사 사진 그룹 탐색 및 미리보기. **유사 동영상 탐지 기능은 제공하지 않음** |
| **파일 편의 도구** | 일괄 파일명 변경, 이미지 형식 변환, 사진 EXIF 정보 확인 |
| **백업·폴더 비교** | 폴더 및 ZIP 사이의 파일 차이 비교 |
| **설명서·정보** | 프로그램 사용법, 버전 및 제작자 정보 |

### 안전성을 고려한 설계

- 검토·보호 대상 구분과 정리 전 결과 확인
- 정리 대상의 기본 선택 해제
- 실제 처리 전 모의 실행(Dry Run)과 사용자 선택 흐름
- 삭제 대상에 대해 Windows 휴지통 이동 방식을 활용
- 중복 파일 정리 시 보관할 원본의 보존 검증
- Windows 디렉터리 정션 순회 방지 및 접근 오류 시 부분 결과 표시

**참고:** 모든 파일을 자동으로 안전하게 분류하거나 유사 사진을 100% 정확하게 판단하는 프로그램은 아닙니다. 원본과 유사 사진은 사용자가 직접 확인한 뒤 처리해야 합니다.

## 🚀 간단 사용법

1. [Releases](https://github.com/dlckdtnr1212-lang/JY-File-Cleaner/releases)에서 ZIP 파일을 내려받습니다.
2. ZIP을 원하는 폴더에 **전체 압축 해제**합니다.
3. `JY_File_Cleaner_v2.0_Beta.exe`를 실행합니다. 프로그램 구동에 Python 설치는 필요하지 않습니다.
4. 왼쪽 메뉴에서 작업을 선택하고 검사할 폴더를 지정합니다.
5. 검사 결과의 분류·경로·크기·보호 상태를 확인합니다.
6. 파일 이동·변경·휴지통 정리는 **중요 파일이 아닌지 확인한 후 사용자가 직접 선택**해 진행합니다.

상세 절차는 [한국어 설치 및 사용 설명서](INSTALL_KO.md)를 확인하세요.

- 소스 회귀 테스트 **115개 실행, 115개 통과, 실패·오류·건너뜀 0개**
- WebView2 화면의 파일·폴더 TOP 20 전환 등 주요 상호작용 검사
- Windows 정션 순회 및 접근 실패 보고 처리 확인
- 배포 ZIP 압축 무결성 검사 및 EXE 실행·종료·재실행
- 격리된 합성 파일을 사용한 주요 백엔드 기능·휴지통 동작 확인
- 50,000개 일반 파일 및 10,000장 사진의 개발용 성능 검증은 이전 단계 수행

이 결과는 특정 개발·검증 환경에서 얻은 기록이며, **모든 사용자 PC에서 무오류 작동을 보증하는 의미가 아닙니다.** Windows 11과 WebView2 미설치 상태의 자동 폴백은 별도 실기 검증을 수행하지 않았습니다.

## ⚠️ 알려진 범위와 주의사항

- 유사 사진 검색은 모든 회전·크롭 변형을 찾지는 못합니다. 잘못 묶이거나 누락되는 사진이 있을 수 있습니다.
- 폴더 용량은 하위 폴더를 포함합니다. 부모·자식 폴더가 함께 표시되면 점유율을 단순 합산할 수 없습니다.
- 접근할 수 없는 폴더가 있으면 결과 일부가 누락될 수 있습니다.
- 레지스트리 정리 기능은 포함하지 않습니다.
- 현재 무료 베타이며, 정식 버전 일정이나 모든 PC 호환성을 보장하지 않습니다.
